# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 7.x     | :white_check_mark: |
| < 7.0   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability within **TheBigBrother**, please do not open a public issue.

1. Send an email describing the issue to `chadi0x@protonmail.com` (or contact via your private channel).
2. Include details to reproduce the vulnerability (steps, logs, or proof of concept).
3. Expect an initial acknowledgment within 48 hours.

We appreciate your help in keeping the project secure!
